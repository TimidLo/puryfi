                                                                                                                                                                                                                          Performance

                                                                                                                                                                                                                          Configure the extension's performance:

                                                                                                                                                                                                                          AI Model

                                                                                                                                                                                                                          Warm Up
                                                                                                                                                                                                                          Warms up the model when the extension starts up.
                                                                                                                                                                                                                          Downscale Input
                                                                                                                                                                                                                          Downscales images to the model input size before turning them into tensors. This improves speed and memory usage at no measurable output difference.

                                                                                                                                                                                                                          Editor

                                                                                                                                                                                                                          Prefer Edited Detections
                                                                                                                                                                                                                          Checks whether edited detections for images exist, and if they do, prefers using those over of the model ones.

                                                                                                                                                                                                                          Animated Media

                                                                                                                                                                                                                          Interpolation
                                                                                                                                                                                                                          Performs a scan every this many frames.
                                                                                                                                                                                                                          Determines how similar detections in two different frames must be to perform interpolation between them.
                                                                                                                                                                                                                          Performs interpolation for this many frames beyond the needed to cover for frames not scanned. This can help cover for the model briefly failing to detect some content.
